LinguaForge is a batch document translation generator that hopes to facilitate batch translation processing of a given document tree structure. The current branch is a CLI command line branch.

![GUI](https://img.shields.io/badge/Usage-How_To_Install_LinguaForge-red)

#### If you haven't installed poetry before

 This project uses Poetry to manage our dependencies. In any Python virtual environment, please install Poetry first. For the installation of Poetry, please refer to:

> [Introduction | Documentation | Poetry - Python dependency management and packaging made easy](https://python-poetry.org/docs/#installation)

Or you can use the command directly

```
pip install poetry
```

#### Installation Project

 Installing the project is very simple under Poetry. After cloning the repository and entering the root directory of this project, you only need to

```
poetry install
```

 Wait for the dependency to be installed and you can use it happily!

![GUI](https://img.shields.io/badge/Usage-How_To_Use_LinguaForge-blue)

After the deployment ends LinguaForge, you just need to type in the command line:

```
python -m linguaforge.main "commands"
```

 where the commands value can be the following values

1. **single-doc**
   Translation of individual files is performed interactively via the command line.
2. **single-doc-from-config**
   Translation of a single file according to the given configuration file.
3. **batch-doc-from-config**
   Translate batch files according to configuration files. This command is used to batch process multiple translation files.
4. **remove-trans**
   Delete translations through the given historical file record. When you have translated it before, you will ask if you need such a file. This command can be used when you need to delete the result of a given translation.
5. **gen-sf-config**
   Generate a single file translation configuration template. This template can be used to build new single-file translation configurations.
6. **gen-bd-config**
   Generate batch document translation configuration templates. This command is used to batch process translation configurations for multiple documents.
7. **langs-list**
   Check the list of languages supported by the default language. This command can help you confirm which languages are supported for translation.
8. **format-file-list**
   View a list of supported file format configuration types. This command displays supported file types and is suitable for translation configurations.

If you have more questions, please type

```
python -m linguaforge.main --help
```
